# MiniMax H3 · 4-step LoRA comparison

Side-by-side comparison of three 4-step MiniMax H3 distillations on the same 13 prompts, generated on Kaggle (2× T4) with the AIQUEST Academy notebook:

- **PDMD**: base H3 + [PDMD](https://github.com/ZeamoxWang/pdmd) 4-step LoRA
- **DMAD**: base H3 + [DMAD](https://github.com/Yzmblog/DMAD) 4-step LoRA
- **Fused turbo**: [MATLOWAI fused turbo](https://huggingface.co/MATLOWAI/minimax-h3-fused-turbo-int8-convrot) (Ref2VA)

**▶ Open the comparison: https://teamaiq.github.io/h3-lora-comparison/**

Each test shows the prompt and the three videos in one 16:9 view: play all three in sync, enlarge one, or switch the audio between them. The videos in `videos/` are the original, unmodified outputs.
